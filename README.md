# Smakio Kiosk Android releases

This public repository contains signed Android APK releases for Smakio Kiosk.
The application source code is maintained separately and is not published here.

## Download

Open the [latest release](https://github.com/nshathisi101/smakio-mobile-releases/releases/latest),
then download the APK listed under **Assets**.

On first installation, Android may ask you to allow your browser or file manager
to install apps from unknown sources. Release notes include the APK checksum for
download verification.
